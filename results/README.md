# Results

Three random-seed runs produced a mean test accuracy of **91.16% ± 0.02%**
and a mean test F1 score of **91.21% ± 0.07%** (sample standard deviation).

`three_seed_metrics.csv` contains the per-seed validation, test, F1, and error
direction results. `error_analysis_comparison.png` visualizes the two
misclassification directions and the confusion matrix averaged over all three
runs.

Large run directories, trained weights, cached data, and raw review excerpts
are intentionally excluded from version control.
